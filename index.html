About this tool

Built with Claude Code HTML5 Tailwind CSS No build step Zero dependencies* MIT License

This is a single self-contained index.html file — plain HTML, vanilla JavaScript, and Tailwind CSS (loaded via CDN, marked with * above). There's no server, no framework, and no build tooling: open the file in a browser and it works. It was designed and built end-to-end using Claude Code, Anthropic's agentic coding CLI, from the original parsing logic through this Tailwind redesign.

Paste an object shaped like { "<videoId>": [{ "time": 0, "desc": "..." }], "lastModifiedByVideoId": {...} } — arrays may also be given as JSON-encoded strings.
